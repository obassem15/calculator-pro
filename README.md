# 🧮 Calculator Pro

A powerful Python CLI calculator with advanced features like history tracking, power operations, square root, and smart result reuse.

## 🚀 Features

- ➕ Basic operations (Add, Subtract, Multiply, Divide)
- ⚡ Power operation (**)
- √ Square root
- 🗂️ History tracking
- ❌ Error handling (invalid input, division by zero)

---

## 🛠️ Tech Used

- Python
- CLI (Command Line Interface)
